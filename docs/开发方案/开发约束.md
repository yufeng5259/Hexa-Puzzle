# 开发约束（本轮执行）

适用于 `dev` 分支上的 Honey Garden Cocos 3.8.8 开发。方案见 [README](README.md)。条款编号用于评审时引用。

## A. 流程

- **A1** 直接在 `dev` 开发，不建分支。按 README §7 的步骤提交，每步一次提交，提交信息说明本步做了什么。
- **A2** 不使用 Claude hooks / git hooks 做自动处理；校验通过显式命令执行（`npm run typecheck`、`npm test`、`npm run ui:gen`、命令行构建）。
- **A3** 唯一的人工确认点是 `Prefab结构.md`；生成 Prefab 后由用户用 Creator 打开一次导入。其余全程静默开发，不依赖编辑器。其余问题按重建计划 06 的默认方案执行，不再逐项询问。
- **A4** 不做的内容：Android、微信、真实广告 SDK、音频、动画/粒子/Spine（登记在开发方案 §6 任务表，后续补）、包体压缩/图集、效果图中已删除的功能（体力、排行榜、好友赠送、商店、背包、礼包、关卡选择页）。

## B. 代码

- **B1 不重复生成**：每个脚本、spec、配置只有一份。需要修改就改源文件，不新建 `Xxx2.ts`、`XxxNew.ts`，不保留旧版本副本。
- **B2 不做兜底开发**：
  - 不写“资源/节点/配置缺失时用默认值继续”的分支；缺了就抛错，在开发期暴露。
  - 不写 `try/catch` 吞错、不写 `?.` 掩盖必然存在的引用、不做降级 UI。
  - 不为不存在的平台或旧存档写兼容代码（`schemaVersion` 字段保留，迁移函数为空）。
- **B3 框架来源**：只从 `bighero2415/assets/scripts` 按 [07 复用清单](../重建计划/07_复用清单.md) 复制或改写，登记到 `tools/framework/reference-manifest.json`。不复制 2.x 的 `.prefab/.fire/.meta`，不复制组合根的整树注入、`cc` 原型扩展、SDK、网络、打点。
- **B4 分层**：`game/domain` 不 import `cc`；`framework` 不 import `game`。所有数值来自配置 JSON，代码里不写 96、12、80 这类业务数字。
- **B5 存档**：只有一个存档对象，所有改动走 `begin → 修改 → commit`；领奖写幂等键；**存档提交成功后才播放到账表现**。
- **B6 TypeScript strict**，`tsc --noEmit` 必须通过。

## C. Prefab 与 UI

- **C1** Prefab 只由 `tools/ui-gen` 根据 `specs/` 生成，不手写单个 Prefab，不在 Creator 里手改生成结果（结构定稿、你明确交接后例外）。
- **C2** 页面、弹窗、列表 cell 都是 Prefab，根节点挂与 Prefab 同名的 View 组件。
- **C3** 所有需要访问的节点、组件、子 Prefab 都用 `@property` 绑定（由生成器写入）。**禁止** `getChildByName`、`find`、按下标取子节点、遍历节点树、`getComponent(node.name)`。
- **C4** 固定按钮的点击在 Prefab 的 `clickEvents` 里绑定到 View 的 public 方法；参数用 `customEventData`。
- **C5** 状态（选中、锁定、已领、置灰、限步/普通）用预置子节点 + `active` 切换，不运行时创建。同一页面的多个状态不拆成多个 Prefab。
- **C6** 固定数量的重复项（地图 8 关、签到 7 格、任务 3 行、5 栋建筑等）预置在 Prefab 中，用 `@property` 数组绑定。只有数量不定的列表（信箱、帮助目录、GM）使用 `ScrollableItemGrid`。棋盘格和拼块使用对象池。
- **C7** 弹窗结构固定为 `Root / Backdrop / Content`。
- **C8** 公共部件（TopHud、RewardItem 等）是独立 Prefab，页面放挂点，通过 `@property(Prefab)` 实例化；不手写嵌套 Prefab 实例。
- **C9** 坐标以页面配置为准（853×1844，左上原点），生成器统一换算；顶部/底部分组用 Widget 吸边。
- **C10** View 关闭后丢弃迟到的异步结果；隐藏时解除事件监听；关闭时释放自己加载的资源。
- **C11** 页面在显示前（节点未激活、子组件 `onLoad` 尚未执行）就会调用 `setInfo` 刷新数据。行、格子等组件不得在 `onLoad`/`start`/`onEnable` 中准备 `show()` 要用的状态，需要从 Prefab 读取的初始值在第一次 `show()` 时读取。

## D. 文字与多语言

- **D1** 所有文字是 `Label` + `LocalizedLabel`，内容来自本地化 key，不在 Prefab 或代码里写死中文。
- **D2** 使用**系统默认字体**，不引入字体文件。字号、颜色、描边、对齐取页面配置的文字层参数。
- **D3** 数字（花蜜、关号、步数、分数、倒计时）一律用 Label，**不用图片拼数字**。R-20 数字字形不接入。
- **D4** 只有设计上要求的艺术字用图片：游戏封面标题、R-19 连击评语。
- **D5** 带参数的文本用模板（如 `第 {level} 关`），由 View 填参数，不拼接字符串。
- **D6** 剧情、帮助、信件等成段文案放语言表，结构放配置（如 `story.json`），改文案不改代码。
- **D7** 设计图有的文字按设计图样式；设计图没有的文字统一白字黑描边（生成器 `label()` 自动应用），不逐个调色。所有缺少设计的地方记录在 [缺少美术设计](缺少美术设计.md)，后续统一出图或人工调整。

## E. 资源

- **E1** `arts/` 是只读来源，不修改、不删除；导入产物放 `assets/`，由 `tools/art-import` 生成，带固定 uuid 的 meta。
- **E2** 导入按最大显示尺寸降采样；不放大。
- **E3** 本轮不接入 Spine，模块保持关闭。后续接入时只用 coinbeach24 中 `spine: 3.8.75` 的资源，只复制 `.json/.atlas/.png`。
- **E4** 程序生成的棋盘（木框、凹槽、轮廓）不出图，在运行时生成一次后不重绘。

## F. 验证

- **F1** 每步结束：`tsc --noEmit` 通过；domain 单元测试通过。
- **F2** 生成 Prefab 后：用 Creator 3.8.8 命令行构建 web-mobile，构建日志中没有缺失资源或脚本的报错。
- **F3** 交付时如实报告：已完成、未完成、没有验证的内容分开列出。
