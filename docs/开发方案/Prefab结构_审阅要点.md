# Prefab 结构 · 审阅要点

配合 [Prefab结构](Prefab结构.md) 一起看。下面是编写 spec 时**设计稿没有直接给出、由开发决定**的地方，请重点确认；其余节点都直接取自页面配置。

## 全局

| # | 决定 | 涉及 |
|---|---|---|
| G1 | 重复单元（关卡节点、任务行、签到格、建筑、蜂友卡、照片格等）直接写在页面 Prefab 里，各挂一个组件脚本（文档中的 `[LevelNode]` 等），不做嵌套 Prefab | 全部 |
| G2 | 数量固定的重复项都是预置节点；**只有信箱**用动态列表（ScrollableItemGrid + MailRow） | 全部 |
| G3 | 状态用预置节点切换：灰底常显、金色/选中/已领盖在上面 | 地图、签到、成就、相册等 |
| G4 | 设计稿只画了一种状态的元素（如只有一个格子有锁），其他格子补的同类节点用相同素材、同样偏移，默认隐藏 | 蜂友、相册、衣柜、世界地图、周目标 |
| G5 | 被删除的功能（体力、排行榜、礼包、商店 "+" 按钮）全部去掉；HUD 只保留头像等级、花蜜、提示、设置 | 所有 HUD |
| G6 | 页面中“回相册 / 回蜂友成长 / 回每日任务”这类返回按钮统一绑 `onBack`（关闭当前，回到来源） | 弹窗类 |
| G7 | 棋盘木框与木纹由 `HexBoard` 用 Graphics 每关画一次；格子和拼块用 BoardCell / PieceCell 对象池 | 拼图、无尽、开局预览 |

## 按页面

| 页面 | 决定 |
|---|---|
| MapPage | 背景与 8 个关卡位置取旧主地图稿；HUD、左右栏、入口文字取 T09-01（单机改版）。左栏：七日礼物、本机成就、每日任务、蜂友；右栏：每日补给、花园野餐、旅行相册、**信箱（新增第 8 个入口）**。翻页箭头：上箭头=更高关，下箭头为同图上下翻转。无尽入口两种状态：未解锁（锁+条件）/ 已解锁（最高分条） |
| PuzzlePage | 设计稿没有暂停按钮，用 R-13 暂停图标放在头像右侧；障碍格暂用“锁定道具图标”代替（设计里是程序生成） |
| LevelPreviewPopup | 普通/限步共用；差异只在文字 key（剩余拼块/剩余步数、首通/复玩奖励） |
| GardenPage | 世界地图入口按钮无专属素材，借用金色盾牌图标；建筑价签文字用新模板 `{name} · {count}花蜜`；施工脚手架位置沿用建筑本体位置。**三园建筑落位**：向阳取 T15-01，清风水湾取 R-01 落位 JSON，云上蜂谷取 T15-05（第三园完成稿中的 5 栋位置）；由 `garden/config/layout.json` 在运行时按园设置 |
| EndlessPage | 撤回按钮用“道具空按钮+撤销图标”，暂停用 R-13；托盘 3 个槽位置为估计值；原“排行榜”按钮改为本机纪录，原“每日奖励”改为每日补给 |
| EndlessIntro / Result | 新文案「开始新一局」「本局结束」 |
| SettingsPopup | 开关用 R-08 素材，滑块开/关位置为估计值 |
| AdStatusPopup | T45-01 实际是“每日补给”的冷却状态，这里的冷却态由时钟图标+倒计时组合 |
| GuideOverlay / Toast | 背景不拦截点击（引导需要点到高亮目标） |
| SigninPage | R-11 签到格底图 180×220 拉伸到设计格 201×198；第 7 天：可领/未到显示大礼盒，已领显示野餐帽 |
| AchievementPage | 设计稿徽章位置换成 R-10 徽章；“本机纪录”一行是新增 |
| TasksPage | 设计稿没有进度条，只显示进度文字 |
| MailboxPage | 信件列表区域位置为估计值 |
| CompanionListPage | “跟随中”标记和照片“新”标记设计稿没有素材，用文字标签占位 |
