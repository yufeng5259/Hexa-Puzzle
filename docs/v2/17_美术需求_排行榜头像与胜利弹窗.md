# 蜂巢小镇 v2 · 美术需求 P2-12：排行榜头像、联赛与胜利弹窗（交给 Codex 执行）

更新：2026-11-17。执行方：另一台电脑上的 Codex。使用方：Cocos 程序（Creator 3.8.8，设计分辨率 853×1844）。
规范与 [03_美术切图任务.md](03_美术切图任务.md) 第 3 节相同，下面只写差异。策划依据：[16_无尽排行榜设计.md](16_无尽排行榜设计.md)。

## 0. 一句话目标

无尽活动新增“蜂群联赛”排行榜（每日 / 每周 / 总榜），拼图胜利改为居中弹窗。为此需要：24 个动物头像＋1 个玩家蜜蜂头像、头像底与 5 种头像框、5 个段位徽章、3 色领奖台、排名行、页签、名次牌、3 色礼盒（开/关）、联赛星星、排行榜入口图标、胜利弹窗顶部装饰。共 **55 张** PNG，另交 3 张合成示意图（只做对照，不进游戏）。

## 1. 程序现状（为什么要）

- 现在没有任何排行榜界面，也没有页面效果图（S26 排行榜页、S27 联赛结算是新页面）。参考截图在 `docs/猫咪数独/`（联赛 1、2，次日结算页 1、2），只参考结构，**不要**照搬它的猫狗角色、礼盒造型和配色。
- **复用（不用画）**：`panel_dialog`、`panel_inner`、`btn_green/grey`、`hud_capsule_light`（倒计时胶囊）、`bar_bg`/`bar_fill_*`（星星进度条）、`ribbon_win_gold`（胜利横幅）、`fx_glow_burst`、`fx_confetti_*`、`fx_win_firework_*`、`icon_coin/energy/hint`、`mark_lock`、`reddot`。
- **为什么复用不够**：
  - 头像：现有角色只有蜜蜂，排行榜要 120 个不同的对手，需要一套动物头像；
  - 段位、领奖台、排名行、页签：现有素材里没有这类件；
  - 礼盒：`icon_chest_*` 是紫色单款，联赛需要金、银、铜三档区分名次；
  - 星星：现有 `icon_exp` 是蜜滴，不能当联赛星；
  - 胜利弹窗：`panel_dialog` 是素面米白，需要一个顶部装饰让胜利弹窗与普通弹窗区分开。
- 程序先用占位实现（头像用色块＋动物名首字、礼盒用宝箱、页签用小按钮），交付后换图。

## 2. 风格

- 同现有 v2 UI：清新立体、圆润，暖金和蜂蜜色点缀，光从左上方来，描边风格与 `icon_chest_closed`、`hud_level_badge` 一致。
- 头像动物：Q 版大头、表情友善，**每只戴一件蜜蜂小饰物**，轮换使用：触角发箍、黑黄条纹围巾、小蜜罐、背后小翅膀、六角形发夹、蜂蜜滴形徽章。这是和参考游戏的主要区别，要一眼看得出。
- 所有文件不含文字和数字（名次数字、段位名、倒计时都由程序用 Label 显示）。

### 3.7 共同要求

1. RGBA 透明，四周留 6px 透明安全边（九宫格件按九宫格规范，外缘不留空）。
2. 外轮廓有 1–2 像素的半透明过渡，半透明像素取图形自身的边缘色，不带白、米、黑或原背景色。
3. 在 4 种底色上都干净：白 `#FFFFFF`、米色 `#F6EBD2`、深蓝 `#0E2A5C`、草绿 `#7CC44E`。
4. 24 个头像同一光照、同一描边粗细、同一头肩比例，放在一张 6×4 网格里看起来是一整套。

## 6. 验收标准

1. 55 个文件路径、画布尺寸与第 3 节一致。
2. 头像是一整套：同光照、同描边、同比例；每只都有清楚的蜜蜂饰物；没有直接沿用参考游戏的角色造型。
3. 无任何文字和数字；名次牌中心区平整，可以放数字。
4. 九宫格件拉伸到第 3 节的显示尺寸时，圆角和描边不变形。
5. 礼盒三档、开关两态叠放轮廓偏差 ≤2px；段位徽章逐级明显更华丽。
6. `win_panel_header` 与 `panel_dialog`、`ribbon_win_gold` 组合自然，中间留空能放下横幅。
7. 4 种底色无白边、残边；4 倍放大无锯齿台阶。
8. 清单登记符合第 4 节，SHA 匹配。

## 7. 不需要做的

- 不做 Spine、序列帧动画数据、音效；开盒、升段、飞星动作由程序实现。
- 不重画已有面板、按钮、横幅、烟花、彩带、宝箱、蜜蜂角色。
- 不做头像底色的 6 个变体（程序着色）、灰度锁定态（程序处理）。
- 不改 `assets/`、`tools/`、`config/` 和其他已交付文件。

## 8. 交付后程序侧会做什么

1. 交付前程序按 16 文档用占位实现排行榜、联赛结算和胜利弹窗，不等美术。
2. 交付后运行 `node tools/v2/import-art.mjs --run` 导入，`node tools/v2/build-ui.mjs --run` 重新生成 Prefab，把占位换成正式图；`LeagueBots.xlsx` 的 `avatarId` 按清单 `ids` 校验。
3. `npm run build:apk` 到真机核对：排行榜三页签、100 行总榜滚动、联赛结算开盒与升段、拼图胜利弹窗（普通、挑战、复玩、重复结算），在多种屏幕尺寸下检查。有问题在本文件末尾追加“问题反馈”。
