# 蜂巢小镇 v2 · 美术补充任务 P2（交给 Codex 执行）

更新：2026-11-13。执行方：另一台电脑上的 Codex。使用方：Cocos 程序（Creator 3.8.8，设计分辨率 853×1844）。
前置：P0、P1 已全部交付并通过验收（见 [03_美术切图任务.md](03_美术切图任务.md)、[美术交付清单.json](美术交付清单.json)）。本文件只列**程序接入后发现仍缺的件**，规范与 03 文档完全相同，下面只写差异。

## 0. 一句话目标

补 6 组小件：新手引导的手指、气泡、目标光圈，通用短提示底，无尽满线的加强高亮，无尽玩法说明插图。共约 8 张 PNG，不需要新的整页布局 JSON。

## 1. 为什么要补（程序现状）

| 场景 | 现在的占位做法 | 问题 |
|---|---|---|
| 新手引导（首关拖放、回家、建造、领奖） | 目标按钮放大脉冲 + 一行描边白字 | 没有手指示意拖动方向；白字压在地图/棋盘上不易读 |
| 短提示（活动未开放、等级信息、帮助） | 同上，一行描边白字 | 没有底，复杂背景上看不清 |
| 无尽拖动预览：将被消除的整线 | 用 `六角块/母件/line_highlight.png`（浅青半透明） | 叠在彩色格子上几乎看不出，尤其青蓝、湖蓝、浅紫格 |
| 无尽页“？”帮助 | 只弹一行字 | 玩家不理解“三个方向整线” |

## 2. 清单

全部遵守 03 文档第 3 节统一规范：RGBA、无字、1 倍 = 853×1844 设计坐标下的显示尺寸、可拉伸件出九宫格、多状态尺寸一致、风格以 S02/S04 为准（金棕描边、柔和高光、轻投影）。

### 2.1 新手引导（放 `素材/UI/引导/`，新目录）

| 文件 | 说明 | 1 倍尺寸 | 九宫格 | 用在 |
|---|---|---|---|---|
| `guide_hand_normal.png` | 卡通手指（白手套或浅肤色，金棕描边），食指朝**左上 45°**点按，其余手指收拢 | 140×200 | 否 | 首关拖放示意、各引导步骤点按 |
| `guide_hand_pressed.png` | 同一只手按下态：指尖略压扁、整体下移 4px、指尖处一圈小按压波纹 | 140×200（与 normal 同画布） | 否 | 点按动画第二帧 |
| `guide_bubble.png` | 米白提示气泡主体，圆角、金棕细描边、轻投影，**不带尾巴** | 最小 160×96 | 是，四边各约 40 | 引导文字底，程序按文字长度拉伸 |
| `guide_bubble_tail.png` | 气泡尾巴（朝下的小三角，和气泡同色同描边，顶边无描边以便与主体拼接） | 40×28 | 否 | 程序放在气泡底边，指向目标 |
| `guide_ring.png` | 目标高亮框：金黄发光圆角描边，中间**完全透明**，外侧柔光 | 最小 200×200 | 是，四边各约 64 | 套在被引导的按钮/建筑/拼块外 |

- 手指画布里**指尖位置必须固定**：在清单 `anchor` 写指尖的归一化坐标（如 `[0.18, 0.06]`），程序把这个点对准目标。normal 与 pressed 的指尖坐标一致。
- 手指尺寸 140×200 与配置表 GuideSteps 里的 `handWidth/handHeight` 一致，请勿改。

## 3. 交付清单登记

1. `美术交付清单.json` 的 `uiAssets` 数组追加 2.1、2.2、2.4 的 7 项，格式同 03 文档第 6 节，`"priority": "P2"`、`"batch": "P2-1"`。例：
   ```json
   { "id": "guide_hand", "name": "引导手指", "states": { "normal": "UI/引导/guide_hand_normal.png", "pressed": "UI/引导/guide_hand_pressed.png" },
     "size": [140, 200], "scale": 1, "slice": null, "anchor": [0.18, 0.06], "source": "按 S02/S04 描边风格新绘", "priority": "P2", "batch": "P2-1", "sha256": { "normal": "...", "pressed": "..." } }
   ```
2. 2.3 的 `line_highlight_strong.png` **不要**放进 `uiAssets`（母件目录由程序整目录导入）；在清单新增字段 `p2Additions` 记录文件路径、尺寸和 SHA。
3. 出一张对照图放 `制作记录/补充20261113/对照/`：
   - 把手指 + 气泡 + 光圈叠在 `效果图/S04` 的托盘拼块上；
   - 把 `line_highlight_strong` 叠在 12 色母件各一格和一格空槽上，与旧 `line_highlight` 并排；
   - `toast_bg` 拉伸到 520×88 叠在 `效果图/S02` 地图中部。

## 4. 验收标准

同 03 文档第 7 节第 1–4、6 条，另加：

2. `line_highlight_strong` 的外轮廓与 `empty_well.png` 叠放后边缘完全重合。
3. 手指 normal/pressed 指尖坐标一致（对照图中两帧叠放检查）。

## 5. 不需要做的

- 不改动任何已交付的 P0/P1 文件，不改效果图。
