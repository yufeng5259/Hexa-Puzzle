## 2. 文档状态与使用边界

- 用户明确需求：蜜蜂/蜂巢主题；参考Tile Busters；沿用当前六角拼图关卡与玩法；消耗体力获得金币；每地图5建筑、每建筑5级；建造动画播完后呈现升级；经验、等级与奖励；签到、每日任务、无尽消除活动；音乐/音效/震动设置。
- 助手建议未自动视为用户确认。入场扣体力、三张首批地图、61格无尽、周积分、具体数值与解锁节点均在文档中标为建议。
- 本目录是新版本产品设计初稿，不会自动替换既有五页首版的运行配置、存档与实施入口。游戏现状与新版目标分开记录。
- 用户指定本次所有产物位于 `F:/qiguobing/git/Hexa Puzzle/Project/docs/v2/`。未来本次新增的数值文档、图片、素材和中间产物也遵守此位置；现有 `Project/arts/` 原稿保留，不搬迁、不覆盖。
- S01—S25各有至少一个主要状态效果图；12张六角图集、15张建筑图集及独立透明PNG已有清单。其他细分状态、完整PSD与运行接入未因图集交付而视为完成。
- 截图与H盘参考文档用于参考格式，不将其商店、广告、付费、生命规则或其他游戏内容移入本项目。
