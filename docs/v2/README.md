- 用户明确需求：蜜蜂/蜂巢主题；参考Tile Busters；沿用当前六角拼图关卡与玩法；消耗体力获得金币；每地图5建筑、每建筑5级；建造动画播完后呈现升级；经验、等级与奖励；签到、每日任务、无尽消除活动；音乐/音效/震动设置。
