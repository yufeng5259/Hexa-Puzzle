## 3. 页面结构与基本体验

### 3.1 页面组织

- 普通启动：Loading→主页。首轮未完成则恢复引导。
- 主页展示当前地图、建筑真实等级、玩家等级、体力和金币。
- Play进入当前主线新局或恢复局；建筑入口切换到同一场景的建造模式。
- 签到、任务为弹窗；无尽为独立活动入口与对局；地图选择可回看已完成地图。
- 设置为覆盖当前页面的弹窗，关闭回原页面和原对局。
- 页面与弹窗的逐区内容、返回与遮罩行为由界面文档S01—S25定义。

### 3.2 新手流程

1. 创建或恢复第一关，按现有三个拼块的强制教学完成真实拖放。
2. 首关通关，保存奖励后显示结算。
3. 引导回主页，再进入建造。
4. 指定建筑进行第一次升级；禁止在施工过程中购买第二次。
5. 施工播放、建筑落成、经验入账。
6. 领取一次欢迎奖励，完成首轮引导。

建议首关教学期间的新开/重玩免体力，首通后失效；引导不赠送额外旋转能力。恢复按实际通关、建造和领奖记录定位，不能只靠弹窗曾显示过判断完成。

### 3.3 建议开放节奏

| 节点 | 开放内容 |
| --- | --- |
| 完成首次建造及欢迎领奖 | 正常主页、签到、每日任务 |
| 主线第5关首次通关 | 无尽活动入口及一次轻引导 |
| 当前地图完成 | 下一地图；地图选择中的已完工地图回看 |

开放条件都是建议。旧玩家若已满足条件，进入新版后直接开放，不重跑首关强制引导。每日首次进主页不连续强弹多个系统，以入口红点引导。

## 4. 主玩法：六角拼图

### 4.1 题库与操作保持

- 读取当前正式题库和主线顺序，不按本版美术重新排列答案或修改题形。
- 拼块只能整块平移，合法落点不能越界、压住障碍或与其他拼块重叠。
- 使用全部规定拼块覆盖目标区域即通关，沿用当前模型的真实胜利判定。
- 普通题无步数失败；挑战题按各关现有步数上限判定。
- 成功放置/改变位置计一步；取回也计一步；非法、原位、取消、空操作不计步。
- 最后一步完成目标时先判通关，再判步数耗尽。
- 托盘沿用当前补位和多页规则，适配同时可见的三枚完整拼块。
- 撤销沿用当前“取回选中或最近放置拼块”的语义，挑战关不返还历史步数；重玩是重新开始，不是旋转。
- 提示显示已有正确目标轮廓与冲突信息，不自动放置；成功激活才扣库存，当前同一提示重复查看不重复扣。

### 4.2 主线结果与退出

| 情况 | 结果 |
| --- | --- |
| 首通 | 发放该关一次首通金币，推进当前待通关关号 |
| 失败 | 不发通关金币；提供重试或回家 |
| 保局回家 | 保存当前棋盘、步数、提示和尝试身份，下次恢复 |
| 放弃本局 | 结束当前尝试，不发金币；不再追加扣体力 |
| 确认重玩 | 体力足够才原子替换成新局；不足则保留旧局 |
| 通关结算重开或重复点击 | 不重复发奖，不重复推进 |

通关基础奖励在胜利保存时入账，结算关闭/切页不会丢失；显示失败可以重试展示。新局创建失败不能提前消耗体力。

### 4.3 题库结束与复玩

110关结束后Play显示“复玩”，打开关卡复玩选择；该列表作为S16内容完成变体。已通关题可复玩，建议同样消耗1体力并获得较低复玩金币，不再次领取首通奖。普通复玩20金币、挑战复玩30金币为建议值。

复玩可计入每日通关任务，不回退主线、不解除已有建筑、不制造新地图。现有全部地图完成后显示内容已完成，保留复玩、日常和无尽。

## 5. 体力与钱包

### 5.1 体力建议方案

| 事项 | 新版建议规则 |
| --- | --- |
| 初始/自然上限 | 5/5 |
| 恢复 | 每300秒1点，离线恢复，满值不积攒恢复次数 |
| 新局 | 消耗1点，扣除和新局保存为一次操作 |
| 恢复有效局 | 不消耗；即使当前体力0也可以继续 |
| 胜利/失败/放弃 | 不追加消耗 |
| 重玩/重试 | 作为新局消耗；先确认条件再替换旧局 |
| 首关教学 | 首通前免费，属于建议例外 |
| 奖励体力 | 可以超过5；达到或超过5时暂停自然恢复 |

已有恢复倒计时不因再次扣体力重置；满值以下按累计缺失时间计算。时钟回拨不产生额外恢复；本地时钟不是联网防作弊。详情弹窗提供恢复说明和现有可领取奖励的跳转，不出现未实现的广告、购买按钮。

旧版已有活跃对局迁入后按已入场处理，不补扣一次；体力值、恢复时间与旧扣费记录保留。详细存档迁移在开发前另立测试契约。

### 5.2 资源职能

| 资源 | 主要产出 | 主要用途 |
| --- | --- | --- |
| 金币 | 主线、签到、任务、活动阶段奖励、建造里程碑 | 建筑升级 |
| 体力 | 自然恢复、签到、等级/活动奖励 | 主线新挑战 |
| 提示 | 初始库存、签到、活动、欢迎奖励 | 主线目标轮廓 |
| 经验 | 建造完成 | 玩家升级 |

UI统一称“金币”，图标可以是蜜蜂纹样金币；不另增“花蜜”“建造星币”钱包。经验是成长进度，不可花费。金币不足时显示需要、拥有和差额，并提供去闯关；若存在保局，优先恢复。

## 6. 建造与地图推进

### 6.1 建筑规则

- 每地图5栋，每栋0→1→2→3→4→5，总升级数25。
- 0级为地基/空置状态，不计入五个已建设等级。
- 除首次引导指定目标外，自由选择建筑与升级顺序。
- 下一次费用、当前等级、五点进度与外观来自同一份状态。
- 满级隐藏付费入口、五点全亮，保留短时满级反馈。
- 每完成一次升级获得经验；每栋首次5级有满级奖励，每图首次25/25有完工奖励。
- 不设置长时间施工倒计时；施工动画本身是此次等待。

### 6.2 建造流程与动画时序

建议单次1.5—2秒，以后通过配置调整。

| 阶段 | 可见表现与业务状态 |
| --- | --- |
| 校验 | 校验当前等级、金币、地图和是否已有待完成建造 |
| 接单 | 保存一次扣费与待完成建造记录；界面显示新余额，建筑仍是旧等级 |
| 施工 | 工程蜂带材料入场，敲打与施工烟尘，锁定重复购买及离开 |
| 落成 | 动画结束后提交新等级与经验/奖励凭据；提交成功才显示新外观及新进度 |
| 反馈 | 建筑轻弹、经验飞入等级条，依次展示后续奖励；恢复操作 |

存档至少能识别：本次建造ID、地图/建筑、旧级、目标级、已付费用、待完成/已完成。接单保存失败不扣钱不播放成功；落成保存失败停留待完成，可重试，不能再次收费。

主动离开在短施工期间暂禁；后台/强退不可依赖动画回调保障。重进找到待完成记录时，播放简短补完施工后提交同一次升级。已完成记录只恢复新外观，不重复经验或奖励。

### 6.3 奖励先后

建筑落成→经验条变化→若玩家升级则等级奖励→若建筑满级则满级反馈→若地图25/25则完工奖励→玩家选择前往下一图。多个等级可合并显示奖励明细，不连续堆叠多个全屏弹窗。

### 6.5 换图和回看

25/25保存成功后显示完工弹窗，完工奖励按地图一次发放。玩家可以留在当前图欣赏，也可前往下一图；领完奖励再次打开不再领取。下一图从0/25开始。

地图选择允许回看完成图，回看图不出现购买按钮。返回当前建设按钮恢复真正的当前图；回看不改写建造进度。暂无下一张实际内容时显示“现有地图已完成”，不跳入空场景。

## 7. 经验与玩家等级

- 初始等级1、经验0；每次建筑升级建议获得20经验。
- 初步按每100经验升一级；每图500经验，完成首图将达到6级。此线性方案仅供测算。
- 升级奖励建议每级1体力，每升5级额外1提示（6、11、16级），不增加主线强制难度。
- 等级不作为建筑购买或地图切换的第二道门槛；地图切换看25/25。
- 经验与金币、地图编号、主线关号明确区分，避免多个“等级”混写。
- 建造完成时经验和等级奖励资格一起保存；弹窗用于展示到账奖励，不重复发放。

旧建筑换算经验、是否补发历史等级奖励属于迁移待定项，不自动给老玩家重复发奖；不重置已有建筑。

## 8. 七日累计签到

以下采用累计签到建议：按设备本地自然日，每日可领取一次；漏签不清零、不补领缺失自然日；第七次领取后次日进入下一轮。

| 累计日 | 建议奖励 |
| --- | --- |
| 1 | 金币50 |
| 2 | 体力1 |
| 3 | 金币100 |
| 4 | 提示1 |
| 5 | 金币150 |
| 6 | 体力2 |
| 7 | 金币200、提示1 |

七次合计500金币、3体力、2提示。只有当天可领取格高亮并显示领取动作；已领打勾，未来未领锁定。首页红点仅有奖励可领时出现。不采用补签付费或广告翻倍。

保存成功后才变为已领。跨日保持弹窗打开时先刷新日期再判断领取；设备时间回拨不允许重复领取已使用日期的奖励，不宣称能防设备改时作弊。

## 9. 每日任务

### 9.1 任务结构（建议）

每日3项，全部完成可领一次完成宝箱；设备本地0点刷新。领取、进度和日期归属持久化。每日任务不要求连续胜利、不以购买提示或消耗奖励为目标。

| 任务池 | 目标 | 建议奖励 |
| --- | --- | --- |
| 完成一次拼图 | 当日通关1次，包含复玩 | 金币30 |
| 持续闯关 | 当日通关3次，包含复玩 | 金币50 |
| 修建家园 | 当日建造完成1次 | 金币30 |
| 蜂巢消除 | 当日无尽消除5条线 | 金币30 |
| 消除积分 | 当日无尽获得500新增分 | 金币30 |
| 完成宝箱 | 当日三项全完成后领取 | 金币50 |

默认每天选“1次通关＋3次通关＋一项轮换任务”，每日金币总量160。无尽未开放时轮换到建造；所有建筑满级且无尽未开放的异常/迁移状态，第三项回退为累计放置10块有效主线拼块。

无尽已开放且没有建造目标时，只从无尽任务选择第三项。首日首次建造发生在任务开放前，不追记为当天任务；面板说明从开放起累计。

### 9.2 事件与跨日

- 一次有效通关同时推进所有适用任务，不能因结算重复打开再次计数。
- 建造以落成保存时间归日；开始施工但未完成不计数。
- 无尽多线一次清除按实际条数计数；无尽得分只累计当日新增分。
- 启动、回前台、打开任务和相关操作时校正日期。跨日后新事件计入新任务。
- 当天未领取奖励在刷新时失效，界面标注“每日0点刷新，请及时领取”；不扣回已经领取的奖励。
- “前往”只导航，不自动消耗体力、放弃当前局或执行购买。

## 10. 无尽活动：蜂巢消消乐

### 10.1 活动定位

本版建议“常驻可玩＋每周刷新个人积分奖励”，无在线排名、无体力入场费。高分记录长期保存；周奖励给日常回流目标。无尽不是主线题库的重复抽题，使用独立形状池，不改变主线规则。

### 10.2 棋盘与操作

| 项目 | 建议规则 |
| --- | --- |
| 棋盘 | 半径4的规则六角棋盘，共61格；开局为空 |
| 托盘 | 每批3枚完整拼块，三枚全部使用后补下一批 |
| 形状池 | 1—5格连通形状：单格、直条、折角、分叉、紧凑形等；各朝向登记为候选 |
| 朝向 | 发牌朝向固定；不旋转、不镜像、不改变形状 |
| 放置 | 整块进入空格才合法；越界/重叠/取消不消耗拼块 |
| 落定 | 成功放置后不能取回；本版无撤销、刷新、救场道具 |
| 目标 | 保持空间、消除满线、追求更高分 |

61格与1—5格形状池是待试玩建议；37格可作为对照方案评估，未同时设立两种上线模式。

### 10.3 消除判定

三个轴向对应六个朝向；一条线是该轴上贯穿棋盘边界的完整连续格列，不是任意三格或同色相邻。

一次合法放置后：检查三个轴向全部完整线→收集本次满线→同时移除其格子并加分→若托盘耗尽则补牌→检查剩余可操作拼块。多线交叉格只清除一次；线数按实际满线条数计算。没有重力、下落或清除后自动压实。

颜色只用于识别拼块；多种颜色同处一线仍可消除。拖动预览显示合法占位，能形成的满线高亮，松手成功才提交；不可把预览当作实际得分。

### 10.4 发牌与结束

- 首版使用可配置形状权重，允许同批重复；随机结果和剩余托盘一起保存，重启不重抽。
- 为避免新批次直接无操作，建议补牌时确保至少一枚在当前盘面有合法位置；不保证三枚必能全放，也不保证无限续命。
- 权重与小/中/大形状比例需要独立数值文档和试玩，不在此虚构已平衡概率。
- 剩余托盘中至少有一枚可以放置就继续；全部不能放置才结束。判定在满线清除完成后执行。
- 结束后显示本局得分、最高纪录、本周积分推进；重开免费、生成新空盘，不重发旧积分。
- 手动提前结束需要确认；已经获得并保存的分数仍计入，不额外加结算奖励。

### 10.5 建议计分

设本次放入格数为P，唯一清除格数为C，满线数为L：

`本次得分 = P + 10×C + 20×L + 20×L×(L−1)`。

同一交叉格的清除分只计一次，多线奖励额外增加。第一版不加入连续回合倍率。该公式为待试玩参数，无尽分数不按固定汇率兑换金币。

### 10.6 周活动与奖励

建议周一设备本地0点重置周累计分和阶段领奖记录。奖励示例：

| 周累计分 | 建议奖励 |
| --- | --- |
| 500 | 金币50 |
| 1,500 | 金币100 |
| 3,000 | 提示1 |
| 6,000 | 金币150、体力1 |

本周每阶段只领一次，累计达标可分别领取；全部领完后继续游玩只累计分与纪录，不额外无限产币。

周积分在每次有效放置时增量保存，不等结算重复灌入。跨周未结束的局可继续：保留棋盘与整局分数，重置周进度，仅跨周后新增分计入新周，历史局分不回灌。离线保局没有新增分。旧周未领阶段奖刷新时失效，活动页明确倒计时与领取提示。

## 11. 设置与公共反馈

- 音乐、音效、震动各自独立开关，立即生效并保存。默认开启属于建议；设备不支持震动时显示不可用说明。
- 关闭音乐不影响音效；关闭音效不影响音乐；震动只在允许的反馈点使用。
- 设置与奖励弹窗遮罩阻断底层输入；打开时取消未提交拖动，关闭后继续原局。
- 不增加语言、隐私、商店、恢复购买等用户未要求的可见入口。
- 资源加载失败显示重试/返回；保存失败保留原状态或待完成记录，不能显示虚假扣费、领奖成功。
