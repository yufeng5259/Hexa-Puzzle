## 3. 统一规范（所有切图）

1. **透明 PNG（RGBA）**，边缘干净无白边/黑边，四周留 2–4px 透明安全边。
2. **不含任何文字和数字**。按钮上的“开始游戏/领取/下一关”、关号、金额、“第1天”等全部由程序用 Label 绘制。
3. **1 倍尺寸 = 853×1844 设计坐标下的显示尺寸**。量效果图里该元素的像素尺寸就是目标尺寸（效果图 854×1842，误差可忽略）。图标类可以出 2 倍以提高清晰度，但必须在清单写明 `scale: 2`。
4. **需要拉伸的件出九宫格版**：面板、按钮、胶囊、进度条底和填充、任务行、卡片。尽量做最小可拉伸尺寸，在清单写明 `slice: [左, 上, 右, 下]` 像素。
5. 光照方向、描边粗细、圆角、投影风格全套一致，以 S02/S04 为准。
6. 图标不带底框；需要底框的（侧边入口、HUD 胶囊）底框单独出图。

## 5. 每页布局标注（P0 做 S02/S03/S04/S06，其余 P1）

每个效果图出一份 `素材/布局/Sxx.json`，程序据此搭 Prefab。坐标以**效果图左上角为原点、单位像素**，程序会自行换算到 853×1844 和安全区：

```json
{
  "page": "S06",
  "reference": "效果图/S06_主线通关_BlockHexa风格.png",
  "size": [854, 1842],
  "elements": [
    { "id": "panel", "asset": "UI/通用/panel_dialog.png", "rect": [72, 515, 708, 850], "slice": true },
    { "id": "title_ribbon", "asset": "UI/通用/ribbon_title_blue.png", "rect": [156, 460, 540, 135] },
    { "id": "title_text", "type": "label", "text": "通关成功", "rect": [156, 500, 540, 70], "fontSize": 40, "color": "#FFFFFF", "bold": true },
    { "id": "btn_next", "asset": "UI/通用/btn_green_normal.png", "rect": [148, 1176, 558, 86], "slice": true },
    { "id": "btn_next_text", "type": "label", "text": "下一关", "rect": [148, 1176, 558, 86], "fontSize": 36, "color": "#FFFFFF" }
  ]
}
```

- `rect` 为 `[x, y, w, h]`，x/y 是左上角。
- 文字元素用 `"type": "label"`，写清字号、颜色、描边色（如有）、粗细；数字类写示例值并标 `"dynamic": true`。
- 只标注本页自己的元素；被遮罩盖住的底页不用标注。
- 需要锚定到建筑的元素（建造页的圆点、费用）不用写坐标，写 `"anchor": "building_feet", "offset": [dx, dy]`，偏移量相对建筑脚底。

## 7. 验收标准

1. 每张 PNG：RGBA、透明边干净；在白底、深蓝底（#0E2A5C）、棋盘格底三种底色上检查，无白边和残留背景。
2. 无任何文字和数字（logo 例外）。
3. 同一部件各状态尺寸一致；九宫格拉伸到 2 倍宽、2 倍高后不变形、角不糊。
4. 风格与 S02/S04 一致；按 3.1 节统一，不出现两种金币。
5. 用切图 + 布局 JSON 合成 S02、S04、S06、S17 四页，和效果图并排出对照图，放在 `制作记录/切图20261112/对照/`。
6. 清单里每个文件都存在，SHA 匹配；没有清单外的孤立文件。
