## 制作来源与可复现性

动物头像使用 imagegen 技能的已配置 API 备用 CLI（`gpt-image-2`），一动物一提示词，未切换模型。`avatar_prompts.jsonl` 保存完整最终提示词；`avatar_sources/` 保留原始生成图；`avatar_provenance.json` 保存原始与最终SHA、饰物及玩家裁切来源。模型输出色底先在原分辨率去除，对边缘执行前景色恢复，再统一到256×256透明画布。`prepare_avatars.py` / `finish_avatars.py` 是规格准备及本地后处理，不含鉴权配置。

UI 沿用既有可编辑 SVG 系列，源稿及渲染程序在 `ui/`。礼盒派生自我方 P2-8 源稿，原路径与SHA见 `ui/sources.json`，没有复用猫咪数独礼盒造型。其余为本批同系列原生SVG。旧PNG、原效果图及原稿保持原样。`compose.py` 只组合示意和检查图；执行它不会修改切图。复现需要 Pillow、numpy、scipy；SVG导出需要 Node + sharp，未给项目新增依赖。

## 规则解释与验收边界

17 §6.5 的“开关两态轮廓偏差≤2px”与 §3.5“开盖态盖子斜飞在上方”不能按整张开闭图轮廓相同同时满足。本批按可切换的三档配色分别检查开态、闭态，跨色差0px；开闭保留相同画布和盒身位置，盖子移动及盒口变化如实呈现。未把不同动作轮廓伪报为完全相同，也未改需求文档。

本批只交付美术与离线合成示意，不执行导入、Prefab生成、Creator预览、APK或真机功能验收；这些属于17 §8后续程序接入。未改 `assets/`、`tools/`、`config/`，未重画旧面板、按钮、横幅与蜜蜂全身角色。现有暂存的 `.meta` 属用户原有工作，未纳入本次提交。
