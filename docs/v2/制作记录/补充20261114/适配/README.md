# P2-4 多屏适配用图 · 2026-11-14

7张正式PNG均为新增文件，原图、建筑、效果图和既有交付不覆盖。4张扩展图为1120×2040 RGB，3张地图的原图置于 `[133,99]`，加载图置于 `[133,98]`；两张平板侧景为2304×1844 RGB；边框为48×256 RGBA、`slice:[0,32,0,32]`。

## 原图保护与来源

- 使用 imagegen 技能的 `image_gen.py edit` CLI、gpt-image-2、high quality，沿用本机已授权配置。4张扩画以带保护蒙版的原图画布为输入，2张侧景分别以M01/bg_puzzle为风格参考。主任务提示词保存为6个 `*_prompt.txt`，任务参数在 `generation_jobs.json`；M01/M02右上云山另用512×512方形保护蒙版作局部续画，提示词和参数在 `*_sky_repair_prompt.txt` 与 `repair_jobs.json`，原稿一并保留。
- 接口原生返回分辨率与请求存在差异，原稿保存在 `生成原稿/` 供溯源。最终尺寸只对新绘区域做归一化、结构配准和外圈颜色接续；无论接口是否保留了中间像素，最终都会原样嵌回原图，绝不对原图区域缩放、调色或滤镜处理。
- 纯蓝天空外沿使用原有低频色彩渐变延续，消除新云被固定区域截断的问题。局部云山稿先与自身的保护区域计算色差，再只保留原图外侧新增部分。外圈颜色衔接以原图为固定边界条件，限定只修改新增外圈；不新增建筑、角色或视觉焦点。
- 平板浅版采用略模糊远景，按M01平均亮度的约88%归一化；深版沿用深蓝色系、弱六边形与少量淡金光点。边框用精确像素绘制，最右2px金线、左侧渐隐柔影，全高剖面一致。
