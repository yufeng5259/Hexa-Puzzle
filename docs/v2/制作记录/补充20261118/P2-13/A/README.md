# A档25张：原造型2倍重建

只覆盖18文档3.1列明的25张；不修改既有制作程序与清单。`before/UI/`保存本批覆盖前的原PNG，供统一对照。哈希、精确尺寸、缩半轮廓距离与原配色差值见 `verification.json`。

## 重建方式

- 9张胶囊：沿用P2-2原解析几何、半径、曲面光照公式与历史调色源；在原设计坐标8倍采样，再导出2倍画布。未放大旧胶囊PNG。
- 2张关闭、6张开关：沿用P0源码中的圆角、倒角层、叉号、状态配色，所有笔画按原设计坐标8倍绘制再导出2倍。
- 4张HUD底、2张侧边件、箭头、Logo：原稿是参考截图裁切，无更高清的独立母件；本批保留可编辑SVG向量重描，并从原轮廓建立有符号距离场，在新画布独立求解外缘覆盖率。材质采用原RGB采样拟合的连续三次样条光照色场。没有把旧RGBA整体resize后直接交付；颜色采样依然来源于旧稿，不能把这部分说成重新生成的原始高分辨率插画。最终导出执行 `fit-colour-fields`，避免初始SVG分色量化产生色带。

## 复现

在Project目录以bundled Python执行 `redraw_a.py`，以Node执行 `render.cjs`，再以Python执行 `redraw_a.py fit-colour-fields`，最后执行 `verify_a.py`。需要Pillow、numpy、scipy、opencv、Node sharp。旧源码仅只读；胶囊历史调色取Git提交ab4db64。

## 自检与边界

全部25张精确为旧画布2倍；缩小一半后50%alpha外轮廓双向最大距离0–1原像素，9张胶囊为0。8组状态alpha逐像素完全相同。解析圆角的硬笔画与旧像素栅格差异最多1原像素，属于抗锯齿重建；未改造型或状态配色。`state_alignment.json`保存逐组验证。

`logo_title`实际包含“蜂巢小镇”字样。18共同无字要求与原造型要求存在交叉，本批按03第4.10的logo明确例外保留已有字标，不在其他切图里增加文字。Logo提高清晰度采取同字形重描，未换字体。

视觉迭代：首次参考裁切件分色向量化出现明显色带，判为revise；改为独立轮廓和连续色场后复查通过，未将该中间状态当交付。最终判定见 `visual-verdict.json`。三类正式对照由主任务统一合成。
