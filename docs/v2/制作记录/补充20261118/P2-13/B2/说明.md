# B2：30 张 UI 高清重绘

范围为文档 18 第 3.2 节自九张 `puzzle_btn_*` 至签到格末尾，仅覆盖该 30 个 PNG。`before/UI/` 保存同名原图供对照；未改旧制作脚本、清单和其他交付。

`build_b2.py` 沿用原 `hud_puzzle/build_hud_puzzle.py`、`P1/build_maps/build_assets.py`、`P1/signin_tasks/build_signin_tasks.py` 的几何、渐变和状态配色公式，在原坐标八倍精度下绘制或将原签到多边形程序直接在双倍目标下求值。最终画布准确为二倍；独立复用的签到勾、锁仍使用我方已交付128×128母件，最终仅约84像素显示，不修改母件文件。

九张拼图按钮的原稿是效果图裁切，边缘含少量底页蓝色。新稿将原半径40、pad3的轮廓重新解析绘制，以原完全不透明位置取出的颜色控制点生成单调三次渐变，用原生圆角矩形的符号距离场生成倒角。没有放大完整旧按钮PNG；也没有把效果图底色带入新的半透明轮廓。

验证见 `verification.json`：30 张的画布、原/新SHA、原程序SHA、缩半后的轮廓偏差以及不透明RGB平均差均逐项登记。以 alpha≥128 的形状计算双向最大最近距离，30 张均≤1px；不透明RGB平均绝对差最大约5.42/255（主要来自按钮倒角的连续曲面重建），未改变配色家族。

已实际打开 `visual_before_after.png` 核查。原签到的 today 外辉光、claimed/locked 下部徽章都是状态设计内容，保留这些内容使四态的**整张alpha**不同，主体外框几何相同。这与“严格整张状态alpha相同”存在原设计冲突，不能伪报全图alpha一致。
