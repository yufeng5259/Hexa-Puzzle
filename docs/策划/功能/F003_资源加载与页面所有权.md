# F003 资源加载与页面所有权

基线日期：2026-10-28。分类：基础框架；当前状态：**基础已具备**。本篇为开发交接策划，不是新增实现或验收报告；后续完成状态以功能完成目录与对应新证据为准。

## 目标、边界与前置

登记素材、资源scope、异步共享与请求身份、引用释放、失败重试。

前置：无业务前置；遵守全项目素材、Prefab与资源生命周期约束。

## 当前事实与确切来源

ResourceLoader校验资源ID、bundle/path/type/UUID和依赖环，ResourcePool共享加载，ResourceScope作为持有边界。BaseView在销毁回合后release；GardenAssetStore继续承担原稿manifest与资源登记边界。

当前证据：[Project/assets/scripts/framework/resources/ResourceLoader.ts:26](../../../assets/scripts/framework/resources/ResourceLoader.ts#L26)；[Project/assets/scripts/framework/core/ResourcePool.ts:27](../../../assets/scripts/framework/core/ResourcePool.ts#L27)；[Project/assets/scripts/framework/ui/BaseView.ts:50](../../../assets/scripts/framework/ui/BaseView.ts#L50)。规则参考以[唯一原型策划案](../../../../prototype/策划案.md)、[落地方案](../../../../prototype/Cocos落地开发方案.md)为来源；原型脚本不等于生产已接入。旧G005–G010、备份工程和全套Prefab存在均不作当前业务完成证明。

## 数值规则与状态流程

登记→加载→scope持有→实例使用→销毁实例→释放scope。共享同一资源不等于共享页面所有权；一个页面关闭只减少其持有，不影响其他页面。失败缓存允许重试，未登记/类型或UUID不符直接失败，不能静默换图。

## 数据权威、提交与幂等

资源记录包含id、bundle、path、type、uuid；scope包含释放状态和请求身份。它们不写玩家档也不派发获奖事件。请求结果只有当前scope和当前页面身份都有效才能应用；业务存档由F017统一拥有，避免把资源目录当成玩家状态。

## 页面、美术与Prefab接入

无独立产品页面；通过所属页面或应用装配接入，不新增平行入口。

已有页面从FoundationBoot.prepare创建scope并交给ViewHost/BaseView；新增通用资源沿用ResourceLoader登记，源页面继续GardenAssetStore。正式Prefab及图片均按目录注册，禁止用绝对磁盘路径或全局releaseAll代替登记。

本功能不要求新建整页Prefab；复用上述证据所指现有装配/组件，不用运行时补树制造页面。

原稿/切图登记沿用[source-art-manifest](../../../assets/resources/framework/config/source-art-manifest.json)与[prefab-registry](../../../assets/resources/framework/config/prefab-registry.json)；静态装饰保留来源布局，真实文字、数值和状态独立绑定。未列业务字段需在所属正式Prefab补typed@property及序列化事件，不扫描名称或补整棵树。

## 生命周期与失败处理

销毁在load完成前也应完成本scope的退订，晚到Asset不能复活旧节点；释放幂等，失败重试创建有效请求身份。源图派生仍需保留来源、哈希与重建方式，不能因共用加载器绕过原稿审核。

## 开发验收场景

1. 两个页面同时读同一资源，关闭一个后另一个仍正常显示。
2. 装载中关闭页面，晚到结果不挂节点，最终引用不残留。
3. 首次bundle失败后重试成功，没有永久失败Promise。
4. 错误UUID/类型/未登记ID返回明确错误，不使用替身图。
5. 重复close/release及子先销毁不抛异常，实例先于资源释放。
