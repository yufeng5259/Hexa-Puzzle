## 生命周期与失败处理

未知旧版本、缺题ID或非法摆放保留原数据与可诊断原因，不能清空余额求通过；事务失败仍使用未迁移原档并允许重试。丢失claims时不得以“补偿”重发全部首通，需明确记录疑点交数据恢复流程。

## 开发验收场景

1. 旧普通80/限步最佳及花蜜建筑完整保留，映射到正确96主线。
2. 同一档迁移两次字节等价或语义等价，不新增奖励回执。
3. 旧限步17..30活跃局可恢复，产品地图仍没有97/储备入口。
4. 旧待处理广告迟到仍归原attempt，不写当前新局。
5. 迁移写失败原档/备份可恢复，余额与claims不半更新。
6. 非连续旧已通保留可复玩，未知字段按兼容策略保留或记录。
