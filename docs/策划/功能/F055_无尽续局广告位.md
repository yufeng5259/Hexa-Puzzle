# F055 无尽续局广告位

更新：2026-10-28。当前状态：**业务未接入**；本篇是后续开发合同，本轮仅文档核对，未运行服务、Creator或平台SDK。

## 目标与依赖

无尽确无合法落点时，以可预览且验证有效的清理方案提供一次自愿续局，不把随机清空作为奖励。

## 规则与状态

仅所有剩余候选均无合法落点、run未结算且continuesUsed=0时评估；按F033方案预览指定格集，在克隆盘上验证至少一块可放才显示视频。每run一次，并受统一频控；不发花蜜、不重发候选、不重置分数/随机状态。免费收获按正常结算与有效局门槛执行，返回/继续处理保持清晰。清理不是普通摆放，不计清线分或任务摆放。

## 数据、提交与幂等

冻结profileId/runId、board版本/摘要、候选及随机快照、clearCells和requestId。回执只对原快照清理并设置continuesUsed，使用统一事务保存消费键。若新run已开始或旧run已结算，迟到仅生成可恢复原run记录或按已冻结终态契约拒绝，不能清新盘；不能用当前盘重新算奖励范围扩大收益。

## 组件接入与生命周期

复用上述正式Prefab及已有UUID。现有字段不足时补有具体类型的@property并在Inspector绑定；固定Button事件序列化指向所属View公开处理入口，不扫描名称或运行时拼完整页面。公共列表使用独立item与可见范围复用，ScrollView/Mask/content保持唯一所有者。显示订阅、隐藏解除；销毁使请求身份失效，先销毁实例再释放所属scope资源，不releaseAll，不覆盖原稿。异步迟到不复活旧页，缺引用初始化明确报错。

## 验收清单

1. 构造无位置盘，预览格与实际清理格完全一致，清后真实可放至少一块。
2. 无有效方案或已续过时无可用广告，免费收获仍能进入结算。
3. 续局保留runId、分数、候选、种子、撤回使用状态，清理不加分/计摆放。
4. 清理后再次无位置不可第二次续，正常结束可达。
5. 切新run后迟到、重复回执、重启恢复均不清新盘且旧奖励只应用一次。
6. 写盘失败不半清盘、不占成功次数，后台恢复不重复清理。
