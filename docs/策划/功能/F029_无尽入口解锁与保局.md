# F029 无尽入口解锁与保局

## 规则与流程

真实通关主线第4关才解锁；解锁不花货币、不看广告。存在未结算run时主按钮为继续无尽并恢复同一个runId；没有活跃run时才创建新局。开新局会丢弃未收获进度，须经确认或先收获，取消则原局完整保留。主线关号沿F008统一映射，不能把展示关号、调试选中或复位夹具当完成。

入口读取完成记录→未解锁说明第4关并可返回主线→已解锁检查活跃run→继续或新建→进入endless。创建时先生成唯一runId、种子、首轮候选和初始快照并持久化，成功再导航。重复点击同一次创建复用回执，导航失败不再造run。返回、暂停和冷启动均优先恢复，不默认重新发牌。

## 数据、事务与事件

F017持有activeEndlessRunId及run快照，主线完成只读F008。run包括id、seed/rngState、board、tray、score、combo、placements、continues、undoUsed、previous、settled。初始前2局固定种子对照原型20261016及20261017，后续用可保存随机状态；原型endlessRuns只在有效结算后加一，其与“前2局”起算的最终生产口径需明确，不擅自改为点击次数。

字段为对照原型的目标业务契约，须归入F017/F019/F022约定的统一模型；不能将prototype/app.js或meta.js整段拷入生产，也不能由View直接写库存。

## 组件接入与生命周期

EndlessIntroPageView接收unlocked、activeRun摘要和start/resume端口，UIFlow挂载EndlessPageView；不让View持有随机生成器或存档副本。帮助与引导复用同一入口资格。加载过程附导航请求身份，关闭入口取消自己的待加载实例，不能销毁已保存run。

继续复用[UIFlow](../../../assets/scripts/app/UIFlow.ts)导航、[GardenAssetStore](../../../assets/scripts/features/garden/resources/GardenAssetStore.ts)登记校验与所属页面资源边界。稳定引用用Inspector强类型绑定，缺项报错；显示订阅、隐藏解除，销毁取消任务与迟到请求，资源addRef/decRef对称。

## 可执行验收

1. 只选中第4关、但未通关：入口仍锁；真实完成后立即解锁。
2. 活跃run退出再进：id、棋盘、三个候选、分数与随机状态一致。
3. 继续按钮快速双击或加载失败重试：不创建第二run。
4. 活跃局点击新局后取消：棋盘与撤回次数不变。
5. 确认新局：旧run不被当有效完成刷任务，新run只创建一次。
6. 首两局固定种子与存档恢复可重现，第三局规则按确认后的起算口径验证。

以上为开发后的验收用例，需保留实际操作和Creator预览证据；本次只编写策划，未运行服务、Creator或生产测试，不将静态Prefab检查替代实际业务验收。
