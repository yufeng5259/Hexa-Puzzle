# F036 亲密度成长与里程碑

让每日任务领取产生可追溯的本地蜂友成长，里程碑只解锁陪伴表现。查看成长、重复点里程碑或切换蜂友不会直接增加亲密。

## 规则与流程

每成功领取一项每日任务，给领取瞬间当前跟随且已解锁蜂友+1亲密；全局每日最多获得3点，不是每蜂3点。每蜂独立0至30，上限30。达到5自动开放专属招手，15开放对应故事，30开放专属饰物；不增加战力、花蜜产量或解题能力。原型当前蜂友已30时此次不加亲密，也不消耗affinityToday，切换其他蜂友后后续尚未领取任务可继续加。

F041校验任务资格和唯一领取键→在同一领取事务锁定selectedBee→发花蜜并按日额度增加该蜂亲密→保存→事件刷新成长页与里程碑。任务完成未领取不加；重复领取不加。跨5/15/30阈值只改变可用状态，不要求另领礼包；点5可播放约1.2秒招手，点15回看故事，点30进入戴取饰物。

## 数据、事务与事件

F017权威affinities[0..2]，selectedBee；F022日期域affinityToday和dayKey。原型affinity为当前显示兼容缓存，生产以数组为唯一权威，不并列维护矛盾数值。DailyTaskClaimed回执包含beeId、affinityDelta、after值；同一个任务键保障花蜜和亲密共同幂等，日切换仅重置今日额度，不重置各蜂总亲密。

字段为对照原型的目标业务契约，须归入F017/F019/F022约定的统一模型；不能将prototype/app.js或meta.js整段拷入生产，也不能由View直接写库存。

## 可执行验收

1. 一天领取3项任务给同蜂：+3；伪造第4个重复领取无增量。
2. 前两项跟随小蜜、第三项花花：分别+2/+1，全局额度3。
3. 亲密4/14/29各领任务：达到5/15/30时对应动作可用。
4. 亲密30时领任务：仍得花蜜、不加亲密且不消耗该次亲密额度。
5. 跨天后总亲密保留，今日额度归零；旧任务回执重放不再加。
6. 连点招手、关页、换蜂友：旧动画不写回新角色，无数值变化。

以上为开发后的验收用例，需保留实际操作和Creator预览证据；本次只编写策划，未运行服务、Creator或生产测试，不将静态Prefab检查替代实际业务验收。
