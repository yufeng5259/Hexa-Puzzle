# F059 微信激励广告平台适配

更新：2026-10-28。当前状态：**业务未接入**；本篇是后续开发合同，本轮仅文档核对，未运行服务、Creator或平台SDK。

## 目标与依赖

把微信激励视频加载与关闭结果映射到统一广告事务，确保无完整观看不奖励、组件关闭后不残留监听。

前置：[F052 激励广告事务状态与频控](F052_激励广告事务状态与频控.md)。优先复用现有app/Controller/Session/服务，不新增第二套存档或奖励权威。

## 当前证据与缺口

Project/build-templates/wechatgame/game.json只声明竖屏及网络超时，不包含能证明可用广告的AppID/广告位资质。当前新TS无微信广告Adapter接通证据；Android旧桥能力不可当微信已实现。

具体依据：[Cocos落地验收规范.md 第49行](../../../../prototype/Cocos落地验收规范.md)；[game.json 第1行](../../../build-templates/wechatgame/game.json)。路由、来源与Prefab登记见[功能清单](../功能清单.json)。

## 页面、美术与入口

原型路由：无独立页面，沿所属业务入口/开发流程触发。唯一原型[prototype](../../../../prototype/index.html)固定4291端口。美术以[现行原型策划](../../../../prototype/策划案.md)与[验收规范](../../../../prototype/Cocos落地验收规范.md)为来源，不另绘已有成品。

无本功能专属Prefab；复用上述前置功能的正式资源及现有资源所有权边界。

## 规则与状态

依平台支持能力创建激励对象，按load/show结果以及onClose的isEnded确认完整观看；undefined/缺失关闭结果不得自行当成功，按真实平台版本合同核验。不把onClose的取消等同奖励，也不在load成功就加库存。无填充/错误/不支持时提示暂不可用并保留免费路径，前后台不得静默触发第二次show。

## 数据、事务与幂等

拟由唯一平台服务装配Adapter并保留requestId、profileId、平台调用代次及pending状态。监听按对象/请求成对on/off，旧代次回调不认新请求；奖励交F052持久去重，微信环境没有原生ACK时也保留领域提交状态供重试。销毁UI不等于删除pending，切档后迟到归原档；GM模拟请求命名空间与真实SDK严格隔离。

## 接入与生命周期

本功能没有独立页面Prefab；平台/验收能力经现有组合层和窄端口装配，需要反馈时复用前置功能正式UI，不另造整页。涉及现有页面的字段仍用typed @property和序列化固定事件。 显示时订阅、隐藏解除，销毁使请求代次失效，先销毁实例再释放scope资源；异步迟到不复活旧页，不releaseAll，不动只读BigHero。必需绑定缺失初始化明确报错。

## 验收清单

1. 微信开发者工具仅验证装配与mock，报告明确模拟；授权真机另测完整观看与真实回执。
2. isEnded=false、无填充、load/show错误、SDK不支持均无奖且免费返回可达。
3. 重复开关/重复加载20次监听不叠加，旧onClose不消费新request。
4. 前后台/退出再进、存储失败重试、重复迟到回执奖励仅一次。
5. 切profile后仍按原归属落盘，未知身份保留诊断，不发给当前档。
6. 真机核对广告位资质/SDK基础库版本及网络，生产配置未知时明确未验。
