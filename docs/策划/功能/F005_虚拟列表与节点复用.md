# F005 虚拟列表与节点复用

基线日期：2026-10-28。分类：基础框架；当前状态：**基础已具备**。本篇为开发交接策划，不是新增实现或验收报告；后续完成状态以功能完成目录与对应新证据为准。

## 目标、边界与前置

可见区加缓冲、item重绑定、横纵向跳转、尺寸变化与监听清理。

前置：[F003 资源加载与页面所有权](F003_资源加载与页面所有权.md)、[F004 通用Prefab组件与绑定](F004_通用Prefab组件与绑定.md)

VirtualList已有scrollView、viewport、content、itemPrefab、itemExtent、spacing、buffer、horizontal；默认extent=100、buffer=2。验证ScrollView/content关系、Mask与左上锚点，拒绝content上启用Layout。

## 数值规则与状态流程

固定尺寸item按可见区加缓冲复用，数据量不等于常驻节点数。setData复制数组、停止自动滚动、回收旧项并回起点；jumpTo对有限数取整并夹在有效范围；resize保留有效偏移且收缩池。横纵向只选择一种，不能与Layout同时争用content。

## 数据权威、提交与幂等

列表拥有只读数据快照、可见索引、复用池及选择回调；不直接修改玩家状态。item必须绑定稳定业务ID而非复用节点名，选择回调交业务Controller校验。异步图带绑定身份，重绑清空旧回调、选中与图，保存与奖励仍通过F017/F020。

## 页面、美术与Prefab接入

无独立产品页面；通过所属页面或应用装配接入，不新增平行入口。

在现有VirtualList.prefab挂原VirtualList，Inspector完整绑定scrollView:ScrollView、viewport:Node、content:Node、itemPrefab:Prefab；viewport预挂Mask。每种业务item使用正式Prefab并挂VirtualListItem兼容渲染组件，不能直接把全量数据拼成节点。

- [VirtualList.prefab](../../../assets/resources/framework/VirtualList.prefab)，脚本[VirtualList.ts](../../../assets/scripts/framework/ui/VirtualList.ts)；现有typed绑定：`content:Node`、`itemPrefab:Prefab`。美术来源：通用组件，无独立整页原稿。

原稿/切图登记沿用[source-art-manifest](../../../assets/resources/framework/config/source-art-manifest.json)与[prefab-registry](../../../assets/resources/framework/config/prefab-registry.json)；静态装饰保留来源布局，真实文字、数值和状态独立绑定。未列业务字段需在所属正式Prefab补typed@property及序列化事件，不扫描名称或补整棵树。

## 生命周期与失败处理

onDisable解绑滚动及尺寸监听，onDestroy清空数据/回调并仅销毁仍有效实例，兼容子节点先销毁。空数据jumpTo无副作用；NaN或Infinity索引明确拒绝，缺模板或锚点错误立即失败。

## 开发验收场景

1. 空、单项、1000项依次设数，驻留数量随视窗而非1000增长。
2. 短→长→空→长反复切换，旧文字、选择和回调不残留。
3. 纵向首末跳转、横向首末跳转均落在对应数据。
4. 缩小/放大视窗保持合法滚动，缩小后池不永久保留旧容量。
5. 快速复用时晚到图片不能覆盖新item；禁用销毁后监听清零。
