# F041 每日三任务与有效事件累计

状态：业务未接入。核对日期：2026-10-28。本篇规定后续开发目标，不表示业务或Creator实机验收已完成。

## 目标与依赖

让玩家通过真实游玩与建设完成每天三件事，按领取而非进入页面发奖励，所有模式通过统一事件累计。每日任务只做本地日期域，不依赖服务器。

前置功能：[F017 持久化玩家存档与写失败回滚](F017_持久化玩家存档与写失败回滚.md)、[F019 花蜜提示钱包与原子交易](F019_花蜜提示钱包与原子交易.md)、[F022 业务时钟与跨日跨周](F022_业务时钟与跨日跨周.md)、[F020 首通奖励与统一幂等结算](F020_首通奖励与统一幂等结算.md)、[F021 普通复玩与每日精选](F021_普通复玩与每日精选.md)、[F023 家园五建筑直接升级](F023_家园五建筑直接升级.md)、[F029 无尽入口解锁与保局](F029_无尽入口解锁与保局.md)、[F034 无尽主动收获与花蜜结算](F034_无尽主动收获与花蜜结算.md)。这些功能提供真实事件和分支权限，不以伪造完成计数替代接入。范围边界以[功能清单](../功能清单.json)为准。

## 规则与流程

play：3有效局领120；build：建设1阶领40，全部三园满级后替换“每日精选”完成1次；endless：累计12次无尽有效摆放领20，无尽未解锁时替换“再拼一关”完成1次。三项合计180，每项每天一次。拼图须真实通关，复玩无花蜜额度时仍可计有效完成；无尽须最终≥6次摆放、≥100分且收获，日摆放只结算有效局的真实次数，不把拖动或秒退计入。

任务控制器接F020真实完成、F023建设和F034有效无尽结算事件，以F022提供的周期键归期→按事件ID去重累计→页面显示未达标/可领/已领→点击领取重校验当日、任务分支与进度→同事务发花蜜、写唯一键→保存→刷新。F022只提供时间，不承担业务事件累计。未达标动作去对应主线/家园/精选/无尽入口；全部满园替换分支沿同一个build任务ID，不允许当天领建设后再领精选。

亲密联动由后续[F036](F036_亲密度成长与里程碑.md)实现：任务领域预留同一候选事务的成长贡献端口，成长服务计算亲密增量，不能在任务View直接写蜂友数组或采用保存后另加一次亲密。尚未接入成长时，本阶段只验任务/花蜜，不显示已经获得亲密；F036负责实际蜂友联动复验，该未接联动不能提前标为完成。

## 数据、事务与事件

沿F017/F022持有dayKey、dailyPlays、builtToday、dailyPlacements、dailyPuzzleCompletions、featuredCompleted和已处理事件；领取键daily:{dayKey}:{play|build|endless}。任务定义只读，分支由统一解锁/消费目标查询派生。DailyTaskClaimed含reward、beeId、affinityDelta与receiptId；花蜜只经F019写入。日切重置当日计数，不清永久领取回执、蜂友或外观。

字段为对照原型的目标业务契约，须归入F017/F019/F022约定的统一模型；不能将prototype/app.js或meta.js整段拷入生产，也不能由View直接写库存。

## 可执行验收

1. 同一真实通关事件重复两次：play只+1，第三个不同完成后可领120。
2. 无尽5次200分收获不计任务；6次100分计1局及6摆放，两个有效局累计12。
3. 三园满级后build行变精选；当天先领建设再变分支仍不可二领40。
4. 无尽未解锁显示拼图1次，解锁后分支切换不重复领取同任务。
5. 三项领取花蜜合计180，双击不重复奖；F036接入后再复验当前蜂友最多+3及花蜜/亲密同事务失败回滚，成长未接时不得显示已获亲密。
6. 跨日旧页面点击领取：按新dayKey重判，不把昨日资格变今日奖励。

以上为开发后的验收用例，需保留实际操作和Creator预览证据；本次只编写策划，未运行服务、Creator或生产测试，不将静态Prefab检查替代实际业务验收。
