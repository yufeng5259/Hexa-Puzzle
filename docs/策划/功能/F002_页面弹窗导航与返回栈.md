# F002 页面弹窗导航与返回栈

基线日期：2026-10-28。分类：基础框架；当前状态：**基础已具备**。本篇为开发交接策划，不是新增实现或验收报告；后续完成状态以功能完成目录与对应新证据为准。

## 目标、边界与前置

唯一页面与弹窗层、来源返回、加载取消与暂停所有权；业务系统通过已有导航扩展。

前置：[F001 启动与Loading](F001_启动与Loading.md)

## 当前事实与确切来源

UIFlow持有单一pageEntry和overlays，UIContext携带presentation、mainlineNumber、levelId、mapPage；mount经请求身份判断后才接受页面。ViewHost仅在已序列化的page/dialog/guide层实例化，并要求根BaseView。

当前证据：[Project/assets/scripts/app/UIFlow.ts:66](../../../assets/scripts/app/UIFlow.ts#L66)；[Project/assets/scripts/framework/ui/ViewHost.ts:8](../../../assets/scripts/framework/ui/ViewHost.ts#L8)。规则参考以[唯一原型策划案](../../../../prototype/策划案.md)、[落地方案](../../../../prototype/Cocos落地开发方案.md)为来源；原型脚本不等于生产已接入。旧G005–G010、备份工程和全套Prefab存在均不作当前业务完成证明。

## 数值规则与状态流程

同一时刻只有最上层可发业务动作；打开弹窗保留来源页面与题目上下文，关闭回到来源，不固定回家园。准备新页立即暂停底下输入，准备成功才替换；失败与取消保留旧实例、旧关卡和旧返回栈。重复同目标导航去重，快速不同目标以最后有效请求为准。

## 数据权威、提交与幂等

上下文是导航数据而非关卡权限。后续选关权限仍由F008判断，余额与领奖由F017/F020处理；UIFlow不得新增独立存储或根据当前route推定已通关。导航请求只提交一次，取消释放候选资源，不提交候选attempt。

## 页面、美术与Prefab接入

无独立产品页面；通过所属页面或应用装配接入，不新增平行入口。

沿用 Main.scene 中 ViewHost 的 pageLayer:Node、dialogLayer:Node、guideLayer:Node；业务页面使用清单登记Prefab。固定按钮序列化发view-action给当前entry，新增业务动作经窄端口交给所属服务，不能在ViewHost写奖励和规则。

本功能不要求新建整页Prefab；复用上述证据所指现有装配/组件，不用运行时补树制造页面。

原稿/切图登记沿用[source-art-manifest](../../../assets/resources/framework/config/source-art-manifest.json)与[prefab-registry](../../../assets/resources/framework/config/prefab-registry.json)；静态装饰保留来源布局，真实文字、数值和状态独立绑定。未列业务字段需在所属正式Prefab补typed@property及序列化事件，不扫描名称或补整棵树。

## 生命周期与失败处理

隐藏时解除view-action并暂停Controller；关闭幂等销毁视图。页面异步失败释放本次scope，现页保持；销毁UIFlow取消pending并逆序关覆盖层。旧层点击、迟到事件和已释放entry全部拒绝。

## 开发验收场景

1. 拼图→暂停→帮助→返回逐层回原局，attempt和步数完全一致。
2. 快速选择6、12、96，仅最终有效选择提交，旧请求实例释放。
3. 新页加载失败保留旧页与来源上下文，可再次点击重试。
4. 覆盖层存在时底页拖放和旧按钮均无作用，关闭后恢复一次。
5. 反复开关设置十次不叠加监听，dispose后无可用入口。
