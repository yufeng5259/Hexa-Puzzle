## 一次做一个功能

建议下一个功能从 [F017 持久化玩家存档与写失败回滚](功能/F017_持久化玩家存档与写失败回滚.md) 开始：当前能保进程内单关，但重启不保存，奖励、建设、任务与广告均需要同一持久化权威。不要重写已经可用的页面层、资源scope、Prefab或题库。

可直接给后续开发对话发送：

> 按 `Project/docs/策划/功能/F017_持久化玩家存档与写失败回滚.md` 完成这个功能，复用当前框架。只实现本功能和必要依赖，保留已有修改；提交实际回归、Creator验证及限制，随后更新功能完成目录，不自动扩展到下一功能。

完成一个功能后，在[功能完成目录](功能完成目录.md)登记完成日期、实际改动、当前源码指纹、测试及Creator/平台证据，更新与其直接相关的状态。独立策划路径与编号保持不变；完成后也不搬走文件，避免依赖链接失效。实施中的新状态以总目录为准，各文档的2026-10-28描述保留为分析基线。
