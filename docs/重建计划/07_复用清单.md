# 07 复用清单

复制代码时，同步登记到 `tools/framework/reference-manifest.json`（AGENTS.md 要求）：

```json
{ "target": "assets/scripts/framework/core/events/EventBus.ts",
  "source": "bighero2415/assets/scripts/core/events/NotificationBus.ts",
  "kind": "A|B", "changes": "改名；删除 bindSourceNotifier；事件 ID 改为字符串枚举" }
```

**判定**：
- **A**：原样复制，只改 import 路径；
- **B**：移植并改写成 3.x API；
- **参考**：只借鉴思路，重新编写。

所有 BigHero 文件路径都相对于 `bighero2415/assets/scripts/`，已核对存在。**2.x 的 `.prefab`/`.fire`/`.meta` 一律不复制。**
