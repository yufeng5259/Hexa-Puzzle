# 04 开发计划

**原则**：

- **先通流程，再做表现。** M1–M4 每个页面达到“真实 Prefab + 真实美术 + 真实规则 + 存档”，转场只用框架默认的淡入和缩放；精细动效、粒子、音效在 M6 统一做。
- 每个任务完成时：单元测试通过，类型检查通过，在浏览器预览中走通验收项，并更新本文的勾选状态。
- 功能编号 Fxxx 对应 `docs/策划/功能/Fxxx_*.md`，规则细节以那些文档为准。
- 工作量：S 约半天，M 约1–2天，L 约3–5天。只是粗估，用于排序，不是承诺。
