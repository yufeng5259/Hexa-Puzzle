# 05 美术需求（交给 Codex 处理）

**读者**：负责补充美术的 Codex。完成后，成品放回 `arts/`，再由开发方接入游戏。

## 0. 交付约定（每一项都必须遵守）

1. **输出位置**：`arts/游戏素材/PNG/补充/<需求ID>_<中文名>.png`。同一需求有多张图时，文件名加序号或状态，例如 `R-08_设置开关_底_开.png`、`R-08_设置开关_底_关.png`。
2. **不改动、不删除** `arts/` 下任何已有文件。
3. **格式**：
   - 一律 PNG（RGBA），除全屏背景外都用透明底；
   - 全屏背景、地形可以不透明；
   - **图里不要写文字**（R-19 的艺术字和 R-20 的数字字形除外）。
4. **尺寸**：按每项给出的“交付尺寸”出图。开发方的流水线会自动降采样到游戏内尺寸，**不要比交付尺寸小**。主体四周留2–4px 透明边，不要贴边。
5. **风格**：与现有美术一致，参考下方“风格基准”和每项列出的参考文件。
6. **清单**：完成后，新建或更新 `arts/补充美术交付清单.json`，每张图一条：
   ```json
   { "id": "R-08", "file": "游戏素材/PNG/补充/R-08_设置开关_底_开.png", "size": [160, 80],
     "state": "开", "nine_slice": [36, 0, 36, 0], "notes": "" }
   ```
   `nine_slice` 是九宫格边距（左、上、右、下，单位像素），只有可拉伸的底板才填，其他填 `null`。
7. **分批**：按优先级交付，P0 先交。每批完成后告知开发方。

- **整体效果**：`arts/页面对照/原页面/` 下的9张图，以及 `arts/效果预览/缺少/` 下的70张页面效果图。

## 非图片类需求（多半需要外部采购，不一定是 Codex 能完成的）

### 音频（P0，目前一个都没有）

**格式**：mp3，44.1kHz。BGM 用单声道 96kbps，每首60–90秒，首尾能无缝循环；音效单声道，每个不超过1秒（升级、通关这两个不超过2.5秒）。

**放在** `arts/音频/`，文件名如下。

| 类型 | 文件 | 描述 |
|---|---|---|
| BGM | `bgm_home.mp3` | 地图和家园：轻快的田园风，尤克里里、口哨、木琴 |
| BGM | `bgm_puzzle.mp3` | 拼图局：轻松专注，节奏稍慢 |
| BGM | `bgm_endless.mp3` | 无尽：稍明快，有律动 |
| 音效 | `sfx_click` | 按钮点击，木质“嗒”声 |
| 音效 | `sfx_pick` | 拿起拼块，轻“啵”声 |
| 音效 | `sfx_drop` | 拼块吸附落下，清脆“咔” |
| 音效 | `sfx_invalid` | 放置不合法弹回，低沉短促 |
| 音效 | `sfx_bloom` | 落地开花，轻柔闪亮 |
| 音效 | `sfx_win` | 拼图完成，上扬的短旋律 |
| 音效 | `sfx_star` | 星星落下，三次依次升调 |
| 音效 | `sfx_fail` | 限步失败，轻柔下行，不刺耳 |

### 字体

- **不能使用**页面配置中指定的微软雅黑：它不能免费商用，也不能随包分发。
- **方案**：正文使用系统默认字体，包体为0；标题使用一个可商用的圆体，开发方只保留实际用到的字，压缩到约200KB 以内。候选：
  - 站酷快乐体，SIL OFL 协议；
  - 阿里巴巴普惠体 Heavy，免费商用。
- **需要你确认用哪个**，见 06 的 E05。数字使用 R-20 的 BMFont。
